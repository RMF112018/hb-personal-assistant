# Screenshot Instructions

Screenshots were not captured in this run because no local dev server/browser capture was started for the evidence pass. Reproduce with:

1. From the frontend directory, run the local dev server with the package script.
2. Open the project schedule route for the Tropical project in the local app with the API server running.
3. Confirm the Schedule Controls sections render: Controls Overview, Trend Analytics, Schedule Health / Feasibility, and Blocked / Not Yet Available Metrics.
4. Capture desktop and mobile screenshots into this package's ui/screenshots directory.

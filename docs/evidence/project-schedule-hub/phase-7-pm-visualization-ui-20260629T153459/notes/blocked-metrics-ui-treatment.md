# Blocked Metrics UI Treatment

Blocked metrics remain visible in the Schedule Controls dashboard but render as unavailable cards rather than active charts.

UDF normalization required:
- Delay Analysis
- Window Start Accuracy
- Window Finish Accuracy
- Should Have Finished
- Critical Issues Category Model

Selected baseline required:
- Schedule Compression Ratio

Cost-weighted progress/SPI variants are not exposed as selectable active metrics unless the backend reports them available.

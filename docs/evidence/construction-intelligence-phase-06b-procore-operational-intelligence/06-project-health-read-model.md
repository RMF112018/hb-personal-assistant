## 1. What was built

- `src/hb_assistant/store/procore_project_health.py` — `build_project_health(project_key, *,
  now_utc, stale_days=7, db_path=None, max_items=25)`. Deterministic, read-only; reuses
  `get_connection` and `get_procore_action_signals`.
- CLI `procore live project-health --project KEY [--stale-days N] --json` (mirrors
  `procore live actions`). Read-only — `SQLiteMigrator().apply()` then read; no network, no writes.

### Dimensions (all from local, project-scoped SQLite)
| Dimension | Source | Output |
| --- | --- | --- |
| freshness | `procore_live_sync_watermarks.last_success_at_utc` | `stale_endpoints` (age_days, stale/never_synced) |
| open work | OPEN `procore_action_signals` | `open_work.open_signals` + high_importance |
| cost / schedule / safety-quality-compliance / overdue | OPEN signals classified by `signal_type` keywords | per-dimension counts + `dimension_signal_breakdown` |
| review-required | `procore_live_records WHERE review_required=1` | count + explicit `review_required_items` |
| relationship quality | `procore_record_edges` | `records_missing_responsibility_edge`, `distinct_responsible_parties` |

Output also: `health_status` (triage label), `status_reason`, `score_components`, `counts`
(incl. COUNT-only `financial_amount_facts`), `top_risks`, `evidence_references`.

## 2. Stop-condition compliance

- **"requires live Procore access"** — avoided: the command queries `project_key` directly over
  local SQLite (like `procore live actions`); `no_live_call_performed: true`. `HB_PROCORE_LIVE` is
  never consulted.
- **"hides review-required high-risk facts behind a single score"** — avoided: there is **no single
  opaque score**. `score_components` is a transparent per-dimension count dict; `review_required_items`
  and `top_risks` are **always listed explicitly**; `health_status` is a documented triage label with
  a `status_reason` trigger list. Proven by `test_review_required_and_top_risks_not_hidden`.

No determinations are made — every dimension is a count of pre-existing signals/flags
(`determinations_made: false`). Read-only: no snapshot persisted, no new migration.

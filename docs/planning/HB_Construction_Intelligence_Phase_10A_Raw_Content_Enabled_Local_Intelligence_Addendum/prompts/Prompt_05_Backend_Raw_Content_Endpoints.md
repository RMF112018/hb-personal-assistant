# Prompt 05 — Backend Raw Content Endpoints

## Objective

Expose raw-content-capable API endpoints.

## Tasks

1. Add/extend email endpoints.
2. Add/extend calendar endpoints.
3. Add `include_raw` and `raw_mode`.
4. Default to raw inclusion when configured.
5. Add endpoint tests.

## Acceptance

- Local API can return raw email/calendar content.
- Metadata/redacted mode remains available.

# Dashboard / Report Contract

## Primary Surface

Implement CLI JSON + raw-free Markdown report first. Add browser/dashboard surface only if repo truth shows a compatible local surface.

## Required Sections

1. Status and data sufficiency.
2. Window and sample size.
3. Brief usefulness trend.
4. Outcome distribution.
5. Rank-outcome alignment.
6. Source-ref coverage.
7. Procore noise by source/family/section.
8. Model degradation and model profile reliability.
9. Feedback calibration lift.
10. Duplicate/similarity proxy.
11. Safe next tuning recommendations.
12. Raw-safety guardrails.

## Report Safety

Do not include raw candidate titles unless repo truth proves they are already bounded/redacted and scanner-clean. Prefer counts, ids, hashes, families, sections, project keys, and reason codes.

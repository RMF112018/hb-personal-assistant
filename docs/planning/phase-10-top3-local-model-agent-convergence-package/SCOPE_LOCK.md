# Scope Lock

This package implements three coordinated candidates in a single branch.

## Candidate A — Daily Brief Intelligence / Synthesis Convergence

Implement a unified final-surface model-enrichment path. Existing model intelligence and synthesis paths must be reconciled so the operator sees one coherent section: **Model Enriched Intelligence**.

## Candidate B — Scheduler / Daily-Run Live Hardening

Ensure the scheduled daily-run path produces the same final surfaces and has strong install/status diagnostics.

## Candidate C — Email Follow-Up Raw Enrichment Productionization

Ensure V45 email raw enrichment is eligible/readiness-aware, integrated into daily-run apply, and consumed in final model-enriched surfaces.

## Out-of-scope unless strictly necessary

- Schema migration.
- New dashboard/frontend.
- Cloud model route.
- Any external writeback.
- Raw-content persistence.
- Browser auto-open.

# 23 Do Not Overclaim Register

## Do not claim

- The model understands project risk conclusively.
- The app determines legal, financial, schedule, contract, safety, payment, claim, or entitlement outcomes.
- The Daily Brief is complete if source coverage is incomplete.
- An extracted commitment is true until user accepted or source evidence is sufficient.
- A task is resolved unless there is accepted local completion or high-confidence subsequent evidence.
- MCP access means Claude has full source access.
- Obsidian write success means user-authored notes were safely untouched unless marker-bound proof confirms it.
- A heavy local model is safe for background use merely because it loads.

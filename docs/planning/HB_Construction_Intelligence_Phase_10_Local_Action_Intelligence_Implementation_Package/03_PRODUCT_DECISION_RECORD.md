# 03 Product Decision Record

## Core product decision

The app should become an action-management assistant, not a data warehouse or passive dashboard.

## Phase 10 product thesis

The highest-value first local AI capability is not general chat. It is a reliable, reviewable action queue:

- extracted tasks and commitments;
- follow-up status;
- waiting-on-me / waiting-on-others classification;
- meeting prep;
- Daily Brief action candidates;
- project signals requiring review;
- Obsidian notes and tags to keep context organized;
- Claude MCP packets that let Claude reason over clean, source-linked context.

## Build now

1. Local model readiness and provider abstraction.
2. AI job queue.
3. Task/commitment extraction.
4. Follow-up monitor.
5. Relationship candidate engine.
6. Review Queue / My Dashboard.
7. Daily Brief action candidates.
8. Obsidian vault manager MVP.
9. MCP context packet builder.

## Defer

- Broad chat interface.
- Autonomous calendar management.
- Writeback.
- Long-term learning/fine-tuning.
- Large vector/RAG expansion beyond existing approved-source retrieval.

# Phase 10 Action Intelligence Runbook

## Operator flow

1. Run source refresh.
2. Run AI jobs dry-run.
3. Open My Dashboard.
4. Review task/commitment candidates.
5. Accept, edit, reject, snooze, or suppress.
6. Review follow-up lanes.
7. Generate Daily Brief action candidates.
8. Prepare Claude packet if needed.

## Rules

- Candidates are not accepted tasks until reviewed.
- High-stakes signals remain advisory.
- Every item must show provenance.

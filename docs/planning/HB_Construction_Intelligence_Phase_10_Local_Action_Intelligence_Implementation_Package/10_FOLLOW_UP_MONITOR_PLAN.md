# 10 Follow-Up Monitor Plan

## Purpose

Track extracted tasks and commitments against later local data to identify unresolved, stale, and likely resolved items.

## Status taxonomy

- `open`
- `waiting_on_me`
- `waiting_on_others`
- `possibly_resolved`
- `stale`
- `snoozed`
- `closed`
- `suppressed`

## Signals

- later reply in same thread;
- calendar meeting occurred;
- Procore status changed;
- user marked local task complete;
- Daily Brief item repeated;
- age exceeds threshold;
- due date passed;
- source became stale.

## UI lanes

- Waiting on Me
- Waiting on Others
- Needs Follow-Up
- Recently Resolved
- Snoozed

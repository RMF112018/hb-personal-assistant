# 12 Daily Brief Action Intelligence Plan

## Purpose

Make the Daily Brief action-first.

## New Daily Brief candidate sections

- Today's Commitments
- Overdue Follow-Ups
- Waiting on Me
- Waiting on Others
- Meetings Needing Prep
- Project Signals Requiring Review
- Decisions Needed
- Obsidian Updates
- Claude Packet Suggestions

## Important rule

The app may assemble and rank local Daily Brief action candidates. If Claude remains the human-readable Daily Brief writer, Phase 10 should prepare clean packets for Claude and optionally write the final Claude output to the approved Obsidian folder.

## Source requirements

Every brief candidate must include source refs, confidence, freshness, and review status.

# Daily Brief External Agent Workflow

## Intent

Today View should optionally display an AI-generated Daily Brief. The brief is generated by an external desktop AI platform/agent as a Markdown file. The app detects the file and renders it as a polished executive brief.

## Setup Requirements

The user selects:

- Daily Brief enabled/disabled;
- external AI platform: Claude, ChatGPT, Perplexity, Other/manual;
- output folder;
- file naming convention;
- generation time/stale threshold;
- included project rule.

The setup wizard provides:

- platform-specific MCP setup instructions where supported;
- copy-ready scheduled task prompt;
- output file path and naming instructions;
- test instructions;
- fallback manual workflow if platform does not support local MCP/file output.

## App Responsibilities

- detect latest Markdown file;
- verify current/stale status;
- parse headings/sections when practical;
- display polished executive brief cards;
- preserve original Markdown as source artifact;
- show generated time, file path, and parse warnings;
- open original Markdown file on request;
- not rewrite or alter substance without explicit transformation notice.

## Today View Daily Brief States

- Not configured
- External AI setup required
- Configured, waiting for next run
- Brief available
- Brief stale
- Brief generation failed
- Markdown parse warning

## Required Brief Sections

Recommended sections:

1. Executive Summary
2. Today’s Meetings
3. Projects Needing Attention
4. Cost / Change Exposure Signals
5. Aging RFIs / Submittals / Decisions
6. Correspondence Worth Reviewing
7. Documents Changed or Requiring Review
8. Vendor / Subcontractor Attention Items
9. Billing / Cash / Retention Attention Items
10. Data Confidence Notes

## Scheduled Prompt Template

Generate a copy-ready prompt with placeholders for output folder/file naming. The prompt must tell the external AI platform to use MCP tools where connected, produce Markdown, save the file, preserve advisory-only language, avoid raw sensitive content, and report insufficient context clearly.

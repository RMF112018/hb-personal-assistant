# Admin / Data Confidence

Admin / Data Confidence is required but secondary. It answers:

- Can I trust this dashboard?
- Is the data fresh?
- Which sources need attention?
- Which jobs failed?
- Are guardrails intact?
- Are permissions too broad or expired?
- Are there review-required or confidence-limited outputs?

## Sections

- Source / Sync Health
- Workflow / Job Health
- Evidence / Guardrail Health
- Retrieval / AI Quality
- Permissions / Governance
- Data Completeness / Coverage

## Primary UI Rule

Operations pages may show compact badges. Detailed diagnostics stay in Admin / Data Confidence.

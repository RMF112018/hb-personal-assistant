# P07 — Dev/Production Mode, Data Quality, and Copy Remediation

Make Dev/Production and data quality clear.

Required:
- visible Dev/Production environment label;
- sidebar footer `Data Quality` indicator with green/yellow/red/gray state;
- hover/focus last-update detail;
- admin-only technical details;
- copy mapper for source states and errors;
- remove internal terms from non-admin UI.

Avoid normal UI terms like `mock_data`, `HB_PROCORE_LIVE`, `token cache`, `source-refresh orchestrator`, `guardrail`, `proof`, raw endpoint paths, and stack traces.

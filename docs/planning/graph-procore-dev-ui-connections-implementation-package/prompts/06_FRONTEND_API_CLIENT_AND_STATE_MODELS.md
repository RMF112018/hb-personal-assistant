# P05 — Frontend API Client and State Models

Create typed frontend API client methods and normalized source status models.

Required:
- confirm Vite/dev backend proxy or base URL;
- add client methods for environment, aggregate status, Graph status/auth, Procore status/auth, refresh actions, scheduler status, daily brief status;
- add TypeScript types;
- normalize network/404/500 errors into user-safe messages;
- prevent raw JSON dumps in normal UI.

Tests should cover response mapping, action URL selection, and failure copy.

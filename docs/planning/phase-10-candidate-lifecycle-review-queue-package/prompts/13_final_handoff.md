# Prompt 13 — Final Handoff

## Objective

Produce final handoff in `docs/evidence/phase-10-candidate-lifecycle-review-queue/11_final_handoff.md` using `FINAL_HANDOFF_TEMPLATE.md`.

## Required content

- branch
- commit SHA
- changed files
- tests run
- DB copy validation results
- migration result, if applicable
- candidate counts
- review queue counts
- lifecycle transition counts
- accepted task/commitment counts
- rejected/snoozed/merged/suppressed counts
- source-ref coverage
- project-key coverage
- duplicate/idempotency result
- guard-column result
- no-raw-leak result
- usefulness gate result
- daily-brief rendered-output result
- known failures
- production safety statement
- merge readiness statement

## Final user-facing response

Do not paste raw evidence. Provide summary, commit, tests, safety statement, and merge readiness.

# Prompt 11 — Raw Safety and No-Leak Hardening

## Objective

Harden lifecycle/review/feedback/daily-brief outputs against raw private content leaks.

## Forbidden output

- raw email body text
- raw HTML
- full recipient arrays
- full attendee arrays
- join URLs
- private web links
- signed URLs
- download URLs
- tokens/secrets
- authorization headers
- bearer strings
- model prompts/responses
- unbounded subject/title/body text
- raw Procore detail blobs
- raw calendar descriptions

## Required tests

Create `tests/test_phase_10_candidate_lifecycle_no_raw_leak.py`.

Use sentinel strings in fixtures for:

- URL
- email address
- bearer token
- raw body phrase
- HTML tag
- join URL
- signed URL marker
- prompt/response marker
- raw Procore blob marker

Assert no sentinel appears in:

- review queue JSON
- lifecycle operation JSON
- feedback JSON
- daily brief rendered markdown/html
- evidence files generated by validation helpers

## Required scans

Use `templates/no_raw_leak_scan.md`.

All evidence must be scanned and recorded in `09_no_raw_leak_scan.json`.

- `incorrect_extraction`
- `already_handled`
- `wrong_project`
- `too_low_confidence`
- `not_project_related`
- `stale_context`
- `private_or_sensitive`

- `waiting_for_reply`
- `waiting_for_meeting`
- `waiting_for_date`

- `other`

- `same_source`
- `same_thread`

- `recurring_false_positive`
- `non_actionable_source`

- `other`

- `completed`

- `resolved_by_meeting`

- `superseded`
- `other`

- `new_source_activity`
- `operator_reopened`
- `snooze_returned`
- `incorrectly_closed`
- `other`

# Example AEOS Feature Flow

## 1. Discovery

Create a repository-truth report.

## 2. Architecture

Create an architecture artifact with acceptance criteria.

## 3. Implementation Planning

Create an implementation plan and local-agent prompt.

## 4. Plan Review

Review the plan and issue APPROVE / REVISE / REJECT.

## 5. Implementation

Local agent implements and produces an implementation report.

## 6. Evidence

Collect command outputs, tests, runtime validation, and git status.

## 7. Audit

Audit the actual diff and evidence.

## 8. Corrective Review

Verify remediation of each finding.

## 9. Go/No-Go

Issue bounded merge/deployment/production decisions.

# Claim Taxonomy

- `VERIFIED`: supported by directly inspected repository/runtime evidence.
- `CLAIMED_NOT_VERIFIED`: asserted by a report or agent but not independently substantiated.
- `ASSUMED`: deliberately used assumption, clearly disclosed.
- `UNKNOWN`: information required but not established.
- `UNAVAILABLE`: evidence could not be accessed; include reason.
- `NOT_APPLICABLE`: criterion does not apply, with justification.

Do not collapse these categories into a generic “done.”

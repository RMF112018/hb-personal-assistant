# Final Report Contract

Every implementation or corrective invocation must report:

1. bounded disposition;
2. repository path, branch, dirty state, base SHA, and current SHA;
3. active goal, state, authorization, and work item;
4. files changed;
5. implementation summary;
6. acceptance-criteria matrix;
7. tests and exact results;
8. evidence paths and hashes;
9. deviations;
10. known issues and unverified areas;
11. final Git status;
12. recommended next gate.

A recommendation is not an authorization.
